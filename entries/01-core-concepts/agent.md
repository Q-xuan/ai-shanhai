## 一句话解释

Agent 就是一个能「自己动手干活」的 AI:你不只说一句话它答一句,而是给个目标,它自己会拆步骤、调工具、改文件、跑命令,直到把事办完。

## 展开说说

普通聊天机器人是「一问一答」:你问,它答,完事。Agent 多了一层循环——**观察 → 思考 → 行动 → 再观察**。比如你让它「修一下这个报错」,它会自己读报错、打开相关文件、改代码、跑测试,测试红了继续改,全程不用你一步步喂指令。

在 AI 编程工具里,Kimi Code、Claude Code、Cursor 的 Agent 模式都是这个意思:AI 从「顾问」变成了「实习生」——能干活,但你得验收。

和 Chatbot(聊天机器人)的区别记住一句话:Chatbot 给建议,Agent 直接动手。

## 你会听到有人这么说

> 「别手动改了,开个 agent 让它把这几个测试跑绿。」

> 「这个 agent 跑了十分钟,自己把重构做完了,还顺手修了俩 typo。」

## 老司机锐评

Agent 很能干,但它的「能干」和「闯祸」是同一个东西的两面。给它权限越大(自动改文件、自动跑命令),越要在关键节点留人工确认。别把生产数据库的钥匙交给一个实习生。
